# 画面デザインのプレビュー

リポジトリのルートから `python3 -m http.server 8765 --bind 127.0.0.1 --directory preview` を実行し、ブラウザーで http://127.0.0.1:8765 を開く。`preview/index.html` を直接開くことも可能。

320×240の画面案。タブ切り替え、状態選択、照明操作、送信中表示をブラウザー内だけで再現する。通信や本体への書き込みは行わない。送信時間は確認用に短縮している。各タブの状態は独立して保持する。フォントはPCのものを使うため、実機の表示と完全には一致しない。

デザインは `src/lighting.cpp` の描画・タッチ判定にも反映済み。プレビューと実機は別実装のため、変更時は双方を更新する。実機の日本語フォントによる文字幅とタッチ操作は実機で確認する。
