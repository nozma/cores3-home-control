# 自動制御

上部の「自動制御」タブで、両方の照明に共通の設定を変更します。初期状態は無効です。時刻は日本時間で、変更と同時に端末へ保存されます。

| 項目 | 初期値 | 設定範囲（15分刻み） |
| --- | --- | --- |
| 起床 | 6:30 | 5:00〜9:00 |
| 終業 | 17:00 | 15:00〜19:00 |
| 就寝 | 23:00 | 21:00〜24:00 |

| タイミング | キッチン | リビング |
| --- | --- | --- |
| 起床 | 就寝直前の明るさで点灯 | 「普段」で復帰 |
| 起床から60分 | 段階的に100%へ | 明るさ・色を段階的に最大へ |
| 起床60分後 | 100% | 全灯（明るさ・色を推定100%） |
| 終業 | 60% | 60%・色40%（白側から暖色へ3段階） |
| 就寝2時間前 | 40% | 40%・最も暖色 |
| 就寝2時間前〜15分前 | 40%を維持し、15分前に保存して常夜灯へ | 段階的に0%（最小点灯）へ、最暖色を維持 |
| 就寝 | 常夜灯を維持 | 明るさ・色を保存して常夜灯 |
| 就寝15分後 | 消灯 | 消灯 |

終業19:00・就寝21:00の場合、19:00は就寝前の40%・最暖色を優先します。就寝24:00の場合、消灯は翌日0:15です。操作開始時刻なので、赤外線送信の完了には時間差があります。

朝は必要な段階数を60分に均等配置します。リビングの最後の段階は全灯1回で済ませ、直前に最大へ調整する信号は送りません。夜間に調光・調色しない前提で、「普段」の復帰値に就寝直前の保存推定値を使います。初回など保存値がない場合は40%・最暖色を基準にし、必要な校正を行います。

無効から有効へ切り替えると現在の時間帯の目標へ直接合わせます。朝の途中なら、その時点の段階へ合わせて残りの変化を続けます。復帰元が不明なら校正が必要です。有効化では就寝前保存値を更新しません。無効化では照明の現状を維持します。受付済みの送信は完了します。

手動・Alexa操作は次の予定まで維持します。朝は次の段階変更が次の予定になります。送信中の照明の予定は同じ分の間だけ待ち、手動・Alexa操作で取り消します。失敗した操作は自動再送しません。自動制御タブに照明別の結果を表示し、詳細は各照明タブで確認できます。「完了」は信号送信の成功であり、照明の受信を保証するものではありません。

時刻設定の編集は次の予定から適用します。再起動・長い通信断などで過ぎた予定をまとめて実行しません。時刻同期前は実行しませんが、同期前に有効化した場合は同期後に現在の目標を適用します。キッチンの推定状態が未確認なら、実際に点灯させてキャリブレーションが必要です。

## 実機で確認する項目

- 3つのタブ、時刻の増減・上下限、有効／無効、設定の再起動後の保持。
- 有効化時の各時間帯の目標、特に常夜灯・消灯と朝の途中。
- 就寝前保存→常夜灯→消灯→翌朝「普段」の復帰と、朝60分の変化・全灯。
- 終業、就寝2時間前、就寝、就寝15分後の動作。
- 送信中のタブ変更とAlexa後続指示、通信失敗時の照明別結果。
- 画面の文字切れ・タッチ位置・実際の明るさと色。

自動テストとビルドの成功は、これらの実機確認とは別です。

就寝前の減光は105分で必要な段階だけ送信します。標準の就寝23:00では、21:00に両方40%、21:53にリビング20%、22:45にキッチン常夜灯・リビング0%となり、23:00まで維持します。途中で有効化しても、その時点の段階を適用します。

## 共通フッター

キッチン・リビング・自動制御の右下に日本時間の時刻を24時間制（HH:MM）で表示します。時刻未同期時は `--:--`。分の切り替わりで更新します。メッセージは左寄せです。

通知はefontJA_12、設定時刻と時計は読みやすいefontJA_16を使います。全幅300pxから時計の実測幅と間隔8pxを引いて、表示可否を判定します。照明メッセージの最長は「点灯状態に合わせてから調光してください」の228px、自動制御の照明別結果は最大でも「台所:実行不可 居間:実行不可」の162pxです。長い通知は意味を保って短縮し、時計と8pxの間隔を確保できない場合は時計を非表示にし、メッセージを省略せずフッター全幅を使用します。短いメッセージに戻ると時計を再表示します。元の通知文字列は変更しません。実機の見た目は別途確認が必要です。
